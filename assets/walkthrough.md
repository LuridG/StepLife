## 🎯 核心架构与功能模块概览

### 1. 客观路线资产与行走打卡解耦 (Step Tracker)
- **客观路线资产 (`RouteItem`)**：仅包含路线的固定客观属性：**名称、描述、测量人、测量步数、`isLocked` 锁定防误触**。
- **行走打卡履约 (`StepLog`)**：记录某天某人行走某路线的完成记录，输入完成圈数与时间，系统按选定成员的**身高与体重**自动精准换算公里数与卡路里。

### 2. uHabits 风格家务习惯追踪 (Chore Tracker)
- **5天日期矩阵**：直观展示近 5 天完成状态。
- **量化打卡智能缩写 (`NumberFormatter`)**：开启量化属性的家务（如买菜记账 `元`），日期打卡格取消 `✓` 勾选，替换为 `1.2k` / `15k` / `1.5M` 数值智能缩写。
- **单项独立热力图与统计 (`ChoreDetailScreen`)**：点击任意家务进入单独界面，生成该家务的年度 Calendar Heatmap 与成员贡献饼图。

### 3. 统一家庭成员系统 (Unified Member System)
- `Member` 实体融合了姓名、性别、身高 (cm)、体重 (kg)、年龄与自定义步长。
- 步量 Tab 和家务 Tab 共享同一套成员档案库，打卡数据全维度精密关联。

### 4. 极致无瑕图标与桌面端适配
- 拥有全透明无白边的 3D 玻璃应用图标（PNG & Windows `.ico`）。
- 整合 `sqflite_common_ffi` 驱动，支持 Windows / Linux 桌面原生流畅运行及 Android APK 编译。
